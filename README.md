## 🚀 About
<img width="1901" height="958" alt="image" src="https://github.com/user-attachments/assets/6e179ec8-699e-4b15-ac29-751848187445" />

**Blissmet CRM** is a modern customer relationship management application designed to help businesses organize customers, track interactions, and manage relationships more effectively.

Built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Supabase**, it combines a clean, responsive interface with a scalable backend. The project focuses on simplicity, speed, and the essential tools teams need to stay organized.
